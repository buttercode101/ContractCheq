# ContractCheck UI audit — 22 October 2026

Baseline: `2c16714e9f185c44609208c1389433105d6499e7` on `main`.

This pass covers current source and executable local regression checks. It is **not a completed live visual audit**: automatic browser approval failed because the session reached its usage limit. No alternative browser was used to bypass that restriction. Existing screenshots and earlier audit claims are not evidence of current rendering.

## Confirmed findings and fixes

| Finding | Source | Change |
| --- | --- | --- |
| AI was labelled unavailable before configuration arrived | `public/index.html`, `App` configuration state and `.ai-option` | Distinguish checking, connection failure and confirmed unavailability; keep AI disabled until settings load. Clear stale AI selection on reconnect. |
| Initial configuration could remain pending indefinitely | `public/index.html`, mount effect | Use the existing abortable 25-second JSON request helper; reject incomplete pricing settings. |
| Failed configuration had no recovery action | `public/index.html`, landing/pricing connection notices | Add a shared, announced retry panel on every view. Retain its disabled reconnecting control while the request runs. Ignore superseded responses. |
| Pricing controls were disabled without explaining initial loading | `public/index.html`, payment caption | Announce checkout availability checking while configuration is pending. |
| All client-side routes retained the landing browser title | `public/index.html`, view effect | Set descriptive titles for Pricing, saved checklists, legal/support pages and reports. Never put uploaded filenames into tab titles. |
| Notification dismiss buttons were 32 by 32 pixels | `public/app.css`, error/notice controls | Increase them to 44 by 44 pixels. Use existing colour, spacing and control tokens for connection recovery. |
