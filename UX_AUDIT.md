## 2. First-time experience (FTX)

**Strengths [OBSERVED]:** Value prop in one line ("Read the risks. Before you sign."); price anchored in hero ("from R19"); free tier named ("Free score + 3 flags"); 3 full examples + downloadable samples before any upload; How-it-works 3 steps; non-advice boundary repeated (hero, pricing, FAQ, footer of report, Terms).

**Gaps:**
- No guided path for the unsure: user must self-select jurisdiction + role + AI before seeing anything. The safest FTX (try a sample first) is not suggested — `demoCard` blurbs describe topics, not "not sure? start here".
- Upload panel copy "Your next signature starts here" (`:527`) is evocative but doesn't say what happens after choosing a file (scan time, free result, no signup). The "how" lives *below* the upload panel.
- First-run state of key reserves: credits badge appears only post-purchase (`:654`); saved-report shortcut appears only post-unlock — a returning user gets no "welcome back" affordance beyond those conditional elements.
- UK FTX [HYPOTHESIS]: single UK demo + thinner rules (Phase 1 §7) vs. ZA depth — a UK first-timer sees parity in UI but not in results. No "UK is newer" disclosure in-product.

## 3. Core experience (scan → understand → decide)

The core loop is genuinely well-shaped: **score + decision brief + source-linked findings + plain-language guide + questions to ask** is a coherent "confident to sign/negotiate/walk away" arc (Phase 2 §3 calls the decision brief parity-plus). Coverage honesty ("X of Y sections", "needs closer reading", 400-section limit, `extraction-warning` for unreadable text) is best-in-class for consumer legal-tech and directly counters free-AI-chat substitution (Phase 2 §5).

Weak spots in the core:
- **Score comprehension**: explainer states direction only ("higher = more risk"); no bands, no "what moves the score", no rule count. A user cannot judge whether 62 is borderline or safe.
- **Free→paid seam**: locked excerpts without analysis (`:302-310`) tease but don't teach — preview persuades by curiosity, not by demonstrated value. Showing *one* fully-analysed locked issue (or analysis of #4) would prove value more than excerpts do.
- **Reading guide discoverability**: guide is paid-only and absent from free nav (`:550`); free users never learn it exists until the unlock banner mentions it in one clause.
- **Guide search** (`:120-122`): live `aria-live` count is good; but zero-result copy ("Try another word; this does not mean the term is absent…") is the *only* guidance — no suggested terms, no clear button.
